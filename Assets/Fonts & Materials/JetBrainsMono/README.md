# JetBrains Mono

Unmodified regular TrueType font from the [official JetBrains Mono repository](https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/ttf), downloaded 2026-09-22.
Used by the dialogue choice terminal; the novel keeps its original Exo 2 font.
Redistributed with the accompanying `OFL.txt` license, also included in game exports.
